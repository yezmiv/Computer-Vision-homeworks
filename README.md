# Image Enhancement on Synthetically Degraded Images

Comparison of classical image enhancement techniques on color images degraded with reduced contrast and additive Gaussian noise. 
The project implements six methods evaluates them with PSNR, MSE, MAE against the original, and produces side-by-side visual comparisons.

## Repository structure
The project is structured as:

HW1/ is the main folder containing the project:
* images/ contains the three original images: parigi.png, cavallo.png, and mare.png.
* degraded/ contains the corresponding degraded versions of the original images.
* results/ contains the individual enhanced images generated by each processing method, along with the metrics.csv file.
* confronto/ contains the side-by-side visual comparisons of the original, degraded, and enhanced images.
* homework1.py contains the complete image processing pipeline, including image degradation, enhancement methods, visualization, and quantitative evaluation.
* requirements.txt lists all required Python dependencies.
* README.md provides project documentation and instructions for running the pipeline.

## Requirements
The project uses Python 3.9+ and a virtual environment.

Create and activate the virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate 
```

Install the required packages, that are NumPy and OpenCV. 
```bash
pip install -r requirements.txt
```

Run the pipeline with: 
```bash
python homework1.py
```
The generated images and evaluation metrics are saved in the results/ folder.

## Degradation Parameters

The synthetic degradation is applied using fixed parameters for reproducibility:

* ALPHA = 0.6 and BETA = 0 for contrast reduction.
* MEAN = 0 and STD = 15 for Gaussian noise.
* SEED = 42 for reproducibility.
